# Karen Music Director non-negotiables

- Preserve every historical song in the local database.
- Never upload or seed a hosted site from `songs.db` without explicit song-by-song approval.
- Preserve English and S'gaw Karen translations and left-to-right Karen input behavior.
- Preserve Chart, Lyrics, and Database work surfaces.
- Preserve chord-entry navigation, mapped Karen typing, measure insertion, lead notation, spans, rolls, dots, circles, x marks, slash bass, and undo/redo.
- Preserve the New Song wizard trigger; it must not open on ordinary startup.
- Preserve JSON, ChordPro, image, and PDF import review without automatic save.
- Preserve export and print paths.
- Preserve one physical Letter page per print copy, centered instrument per selected copy, and an additional Reference page.
- Preserve editable paper metadata and the print-format header/footer contract.
- Keep visible controls functional, keyboard accessible, touch reachable, and responsive.
- Treat the packaged desktop shell as visual reference and current source/tests as behavioral authority.
