# Issue Priority

Use this order when the operator pastes many annotations or says to fix "all" of the requested families.

## Tier 1

1. Launcher and packaging
2. Import and vision analysis
3. Chart and print preview

## Tier 2

4. Language modal
5. Wizard and metadata form
6. Keyboard and shortcuts

## Tier 3

7. Translation and front-facing text
8. Layout and theme polish
9. Data and song integrity

## Execution rule

- Start with the highest tier that is visibly broken on the operator’s current surface.
- If multiple items are equally visible, choose the one with the smallest safe fix surface first.
- Do not jump past a broken higher-tier issue just because a lower-tier item is easier to edit.
