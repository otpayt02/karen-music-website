# Filled chart review pictures

These three pictures were created from the supplied handwritten photographs through the Karen Music import review workflow:

- `01-go-go-filled-chart-reviewed.png`
- `02-chart-24-slow-filled-chart-reviewed.png`
- `03-move-your-boat-filled-chart-reviewed.png`

The live OCR pass dropped too many chord roots to use as a faithful final draft. The screenshots therefore use conservative, source-grounded chart-code transcriptions imported through the same review screen. The rejected OCR-only screenshot is not part of the proof set.

`capture-manifest.json` records the section and measure totals, the warning text shown at review, a null saved-song ID, and `save_clicked: false` for every chart. No chart was published or added to the song library.

`Move Your Boat` was regenerated on 2026-07-19 using the handwriting default for measures with exactly two chords and no visible beat underlines. In 4/4, the first chord is on beat 1 and the second is on beat 3. Browser state verification checked 83 two-chord measures and found zero placement mismatches.

Before saving, a musician should compare the photographs for the missing Karen titles and ambiguous rolls, melody numbers, phrase arcs, x/dot placements, and figured-bass marks.
